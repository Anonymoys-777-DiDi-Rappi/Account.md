# NEXORA IA PAY

Plataforma de pagos en desarrollo para el producto **Hotmart IA Agente**.

## 📌 Descripción

NEXORA IA PAY es un proyecto diseñado para desarrollar una plataforma propia de pagos que permita administrar enlaces de compra, gestionar transacciones y conectar los pagos con el acceso al producto Hotmart IA Agente.

El objetivo es comenzar con un sistema local y posteriormente convertirlo en una plataforma accesible desde Internet.

## 🎯 Objetivos del proyecto

- Crear una plataforma de pagos propia.
- Generar y administrar enlaces de pago.
- Integrar el checkout oficial de Hotmart.
- Conectar los pagos con Hotmart IA Agente.
- Gestionar clientes y transacciones.
- Incorporar diferentes métodos de pago mediante proveedores compatibles.
- Preparar una futura versión pública.
- Mantener una base de datos para registrar la información necesaria.

## ⚙️ Tecnologías utilizadas

- Node.js
- Express
- dotenv
- Helmet
- SQLite
- better-sqlite3
- Termux
- Android
